# Marknexia Brand Package

This package contains the initial brand identity and production-ready source assets for the Windows Markdown viewer.

## Primary brand
**Marknexia**

**Tagline:** Read. Explore. Understand.

**Descriptor:** GitHub-style Markdown. Native on Windows.

## Asset hierarchy
1. SVG assets are the source of truth.
2. PNG/ICO assets are raster derivatives for app/store usage.
3. Store and social artwork is derived from the same visual system.
4. `BRAND-GUIDELINES.md` defines usage.

## Clearance
This is a branding proposal and asset package, not a legal trademark clearance. Perform formal trademark/domain/store/package namespace searches before public release.
