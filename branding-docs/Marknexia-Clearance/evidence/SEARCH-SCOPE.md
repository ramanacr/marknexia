## Important limitations

Search-engine indexing is not equivalent to a database search. Official trademark portals may contain records that are not indexed by search engines or may require interactive login/captcha/OTP flows. The exact Marknexia string therefore cannot be certified as absent from official registers using search-engine results alone.

The IP India public-search portal currently presents an OTP/captcha workflow. A full official search should be run manually or by a trademark professional with access to the registry.

The Microsoft Store public web index is not authoritative for reserved names. Partner Center's "Check availability" and "Reserve product name" workflow is authoritative for a Store name reservation.

The domain registrar checks are point-in-time availability checks. Availability can change immediately.
