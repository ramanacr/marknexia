# Marknexia Preliminary Name & Namespace Clearance Report

**Date:** 2026-09-05
**Scope:** Preliminary commercial screening for a Windows Markdown viewer / documentation product.
**Candidate:** `Marknexia`

> **Legal notice:** This is a research and risk-screening report, not legal advice, a trademark opinion, or a guarantee of registrability. Final clearance should be performed by qualified trademark counsel in each launch jurisdiction.

## Executive conclusion

### Current recommendation: CAUTION / PROCEED TO LEGAL CLEARANCE

The exact string **Marknexia** produced no obvious web-search results in the searches performed for software, apps, GitHub, NuGet, npm, Microsoft Store, trademarks, or general company/product usage. That is a positive signal.

However, the name is **not yet clean enough to call "cleared"** because the root element **NEXIA** is heavily used and protected in software/electronics/technology-related fields. Examples include live/registered NEXIA marks in the United States and India, including Class 9 computer/software-related goods, and a registered Canadian NEXiA mark for downloadable software. The exact composite `MARKNEXIA` is different, but the shared `NEXIA` element increases the need for professional likelihood-of-confusion review.

There is also an active Indian company named **MARKNEXA MARKETING (OPC) PRIVATE LIMITED**, incorporated in October 2025. Its business is wholesale trade rather than software, so it is not an obvious direct product collision, but it is a close spelling and should be disclosed to counsel.

The current domain screen shows **marknexia.app** and **marknexia.dev** as available through the checked registrar service. **marknexia.com could not be verified because the registrar availability endpoint returned a connection error on repeated checks**; therefore the `.com` status is unresolved, not "available" or "registered" based on this audit.

## 1. Trademark screening

### India

The official Indian Trade Mark Registry public-search portal is available at `tmrsearch.ipindia.gov.in/ESEARCH`. It uses an interactive search flow and currently requires OTP/captcha, so the browser-indexed search cannot be treated as a complete database query from this environment. The portal itself is the authoritative place to run exact, phonetic, and class-filtered searches.

A broad indexed search found **NEXIA** registered in India in Class 9 for audio/networked digital signal-processing equipment containing hardware and software (Application 2056268; proprietor BIAMP SYSTEMS LLC). It also found older Indian Class 9 NEXIA registrations for electronic goods. These are not exact `Marknexia` hits, but they establish an existing NEXIA technology mark family relevant to the assessment.

Sources:
- IP India public search portal: https://tmrsearch.ipindia.gov.in/ESEARCH
- NEXIA India Class 9 record (secondary indexed database): https://www.indiafilings.com/search/nexia-tm-2056268
- Older NEXIA India Class 9 record (secondary indexed database): https://www.indiafilings.com/search/nexia-tm-1247407

### United States

Targeted indexed searches found multiple NEXIA Class 9 registrations/applications, including:

1. **NEXIA - Biamp Systems Corporation**, U.S. Registration 2993281, Class 9, for audio equipment and networked digital signal processing systems consisting of hardware/software.
2. **NEXIA - Nexia Intelligence LLC**, U.S. Registration 4280553, Class 9, for home automation systems and associated software.
3. **NEXiA - Innovation Associates, Inc.**, application/registration family for Class 9 downloadable software for prescription fulfillment operations.

These are strong evidence that `NEXIA` is not a blank technology field in the U.S. `Marknexia` adds the `Mark-` prefix, which can materially distinguish it, but counsel should assess whether consumers could perceive it as a brand extension or otherwise be confused.

Sources:

- NEXIA / Biamp: https://trademarks.justia.com/783/44/nexia-78344886.html

### WIPO / international

WIPO's Global Brand Database supports searches by keywords, names, goods/services, and image similarity, and WIPO recommends checking national/regional registers as well. No indexed exact `Marknexia` result was found in the web screening; the live WIPO database should still be queried directly before filing.

## 4. Microsoft Store

Microsoft states that every Microsoft Store app must have a unique Store name. For an MSIX/PWA app, the name is checked and reserved in Partner Center; Microsoft recommends doing this as early as possible. Reservations can be removed after three months if unused. Microsoft also notes that a name may be unavailable even when no public Store listing is visible because another developer may already have reserved it.

Therefore **Partner Center is the authoritative test** for the Store namespace.

Source:
- https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/add-on/reserve-your-apps-name
- https://learn.microsoft.com/en-us/windows/apps/publish/partner-center/msix/manage-app-name-reservations

## 6. Similar-name risk

The most important finding is not an exact `Marknexia` collision. It is the **NEXIA family**.

Because the proposed product is downloadable software in Class 9, the following deserve attorney review:

- NEXIA / BIAMP - Class 9 software + hardware
- NEXIA / Nexia Intelligence - Class 9 software/home automation
- NEXiA / Innovation Associates - Class 9 downloadable software
- NEXIA / other software/service registrations in Class 42

The risk is **not automatically high**: the complete mark `MARKNEXIA` is longer and contains a distinctive prefix. However, a legal professional should assess visual, phonetic, conceptual, and market-channel similarity.

## 7. Recommended trademark filing strategy

For a product that starts as a Windows desktop Markdown viewer and may expand into documentation tooling/SaaS:

### Primary word mark
`MARKNEXIA`

### Likely Nice classes to discuss with counsel

- **Class 42** - software as a service, hosting, software development, and related technology services if/when those offerings are genuinely used or planned

Do not copy the sample wording above directly into a filing without counsel confirming the exact goods/services specification for the relevant jurisdiction.

File/protect the distinctive logo separately where commercially justified.

## 8. Required final clearance actions

Before public launch:

1. Run exact, phonetic, and similarity searches in the official IP India database.
2. Run equivalent searches in USPTO and WIPO, then relevant launch-market registries.
3. Have trademark counsel assess the NEXIA family and MARKNEXA similarity.
4. Check and reserve `Marknexia` in Microsoft Partner Center.
5. Secure the preferred domain(s) after legal risk is acceptable.
6. Secure GitHub organization and repository names.
7. Reserve/publish package namespaces only after the brand decision is final.
8. Preserve dated evidence/screenshots/PDF exports of the clearance results.

## Final recommendation

**Do not abandon Marknexia yet.** The exact composite appears promising and no obvious direct software collision surfaced in the current screening. However, **do not treat it as legally cleared** because the `NEXIA` component has substantial existing trademark activity in technology/software, including Class 9.

### Overall risk rating: YELLOW - potentially viable, attorney review required

If counsel concludes that the combined mark is sufficiently distinctive and not confusingly similar in the target classes/markets, Marknexia is a strong candidate for the product.
