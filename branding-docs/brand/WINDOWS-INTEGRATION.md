# Windows / WinUI Asset Integration

## App identity
Recommended product display name:
`Marknexia`

Suggested executable / solution naming:
- Marknexia.App
- Marknexia.Core
- Marknexia.Rendering
- Marknexia.Navigation
- Marknexia.Tests

Keep publisher/package identity distinct from the public brand until the Microsoft Store identity is established.

## Icon source
Use:
`logo/marknexia-symbol.svg`

Generate the project-specific Windows icon assets from the SVG master rather than scaling an existing PNG.

Included PNG sizes:
16, 20, 24, 32, 40, 48, 64, 96, 128, 256, 512.

Included ICO:
`icons/marknexia.ico`

## Theme usage
Light theme:
- dark wordmark
- light surfaces
- primary blue accents

Dark theme:
- light wordmark
- dark surfaces
- primary blue accents

## Trademark / affiliation wording
The UI may describe rendering as "GitHub-style" where accurate. Do not use GitHub logos, marks, or product claims that imply affiliation.
