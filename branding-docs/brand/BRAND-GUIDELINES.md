# Marknexia Brand Guidelines

## Brand
**Marknexia**

### Recommended tagline
**Read. Explore. Understand.**

### Product descriptor
**GitHub-style Markdown. Native on Windows.**

### Positioning
A production-grade Windows Markdown viewer focused on GitHub-style rendering, diagrams, smart document navigation, anchors/bookmarks, repository-aware links, offline operation, and secure local rendering.

## Naming strategy

"Marknexia" is deliberately a coined brand rather than a generic "Markdown + noun" product name. This gives the product room to expand into adjacent documentation and knowledge tooling.

A preliminary web/domain screening was performed during product naming. This is **not** trademark clearance and does not guarantee exclusive rights.

Before commercial launch, clear:
- US / EU / India / target-market trademarks
- Microsoft Store product identity
- `Marknexia` GitHub organization and repository names
- NuGet / npm / other package namespaces
- `.com` and relevant country-code domains
- social handles
- app-store search collisions

## Brand personality
- Technical
- Precise
- Native
- Fast
- Trustworthy
- Documentation-first
- Developer-oriented

Avoid:
- GitHub visual mimicry
- mascot-heavy branding
- overuse of gradients
- generic markdown/code clichés

## Logo concept

The symbol combines:
1. A document / folded-page silhouette
2. An "M" monogram for Markdown
3. A connected line motif representing links, anchors, graphs, and repository navigation

## Typography

Primary UI: **Segoe UI Variable** (fallback: Segoe UI)

Code / technical text: **Cascadia Code** (fallback: Consolas)

## Logo usage

Use the supplied SVGs as the master assets.

Do:
- preserve proportions
- maintain clear space
- use symbol-only artwork for small app icons
- use light wordmark on dark surfaces
- use dark wordmark on light surfaces

Do not:
- stretch
- rotate
- recolor arbitrarily
- add shadows/glows to the master logo
- place the full wordmark inside small app tiles
- imitate GitHub's logo or trade dress

## Product language

Preferred:
- "GitHub-style Markdown"
- "GitHub-compatible behavior"
- "native Windows Markdown viewer"

Avoid:
- "official GitHub Markdown viewer"
- wording that suggests affiliation, endorsement, or sponsorship by GitHub
