# Microsoft Store / Product Copy

## Name
Marknexia

## Tagline
Read. Explore. Understand.

## Short description
A native Windows Markdown viewer with GitHub-style rendering, diagrams, smart navigation, and offline-first performance.

## Key features
- GitHub-style Markdown / GFM rendering
- Mermaid and diagram-ready architecture
- Cross-file Markdown links
- Same-document anchors and bookmark navigation
- Repository-aware relative paths
- Syntax-highlighted code blocks
- Light / dark themes
- Secure local rendering
- Fast offline reading
- Windows-native file associations

## Important wording rule
Use "GitHub-style" or "GitHub-compatible" to describe behavior. Do not imply affiliation, endorsement, or official status with GitHub.
