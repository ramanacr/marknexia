Privacy Policy

Last Updated: September 13, 2026
Summary: Marknexia is an offline-first desktop application designed with complete privacy as a foundational principle. We do not collect, store, transmit, or monetize any personal information, telemetry, usage statistics, or user document data.

1. Who We Are

Marknexia ("we", "our", or "the application") is developed and maintained by RRC Labs as an open-source native Windows Markdown viewer and documentation repository browser.

2. Information We Do Not Collect

Marknexia does not access, collect, transmit, or share any personal information. Specifically:

  • No Personal Identifiable Information (PII): We do not ask for, collect, or store names, email addresses, phone numbers, usernames, or contact details.
  • No Analytics or Telemetry: Marknexia contains zero telemetry SDKs, analytics tracking pixels, diagnostic reporters, or third-party advertising libraries.
  • No Document Data Collection: All Markdown files, repository assets, diagrams, and local text rendered by Marknexia remain exclusively on your local storage device. No document text or file contents are ever uploaded or transmitted across the internet.
  • No Account or Registration: You do not need to create an account, log in, or authenticate with any service to use Marknexia.

3. Local File System & Application Data

Marknexia requires access to files you explicitly choose to open (such as .md, .markdown, or folder workspaces) to render documentation and provide repository navigation:

  • File operations are confined strictly to read access within the selected document directory and subdirectories.
  • User application preferences (such as window layout, theme selection, and recent document lists) are stored locally on your device in Windows AppData and are never shared or synchronized externally.

4. Network Communications & External Links

Marknexia operates completely offline with bundled rendering libraries (including Markdig, ColorCode, and Mermaid 11.4). Marknexia does not establish outbound network connections, except when:

  • You explicitly click on an external hyperlink (e.g. https://) inside a rendered Markdown document, which opens the URL in your default system web browser.
  • You explicitly check for software updates via the built-in GitHub Releases updater, which retrieves release metadata solely from the official GitHub API. No personal identifiers are transmitted during update checks.

5. Children's Privacy

Because Marknexia does not collect any personal information whatsoever, it does not knowingly collect or solicit personal data from children under the age of 13.

6. Microsoft Store Compliance

This privacy policy is provided in accordance with Microsoft Store App Developer Agreement (ADA) Policy 10.5.1. By installing Marknexia from the Microsoft Store, your installation is subject to Microsoft's standard Store terms and privacy policies.

7. Changes to This Privacy Policy

Any updates to this policy will be posted on this page and reflected in the "Last Updated" date. Because we do not collect contact information, we encourage users to review this page periodically.

8. Contact Information

If you have any questions or concerns regarding this Privacy Policy or Marknexia's privacy practices, please contact us:
