# Marknexia — GitHub-style Markdown

A production-grade Windows Markdown reader engineered for developer documentation, ADRs, and repository wikis.

Note
Deterministic heading anchor generation guarantees full link compatibility with GitHub READMEs.
Warning
Hostile links attempting directory traversal escapes (e.g. ../../../../Windows) are sandboxed and blocked.

Engineered for Technical Readers

Everything you expect from GitHub's web interface, packaged as a fast, offline-first native Windows application.

⚡

100% GFM Parity

Native rendering of GitHub Alert callouts ([!NOTE], [!TIP], [!IMPORTANT], [!WARNING], [!CAUTION]), task lists, tables, footnotes, and autolinks.

📊

Offline Mermaid 11.4

Full support for flowcharts, sequence diagrams, ER graphs, state machines, and Gantt charts without runtime internet access or CDN lag.

🧭

Repository Navigation

Seamlessly navigate intra-document anchors, relative cross-file links, and repository-root /... paths resolved against the .git boundary.

🛡️

Sandboxed Security

Ganss.Xss sanitizer strips scripts, event handlers, and malicious SVGs. Strict path traversal checks prevent unauthorized filesystem access.

📑

WinUI 3 Modern Tabs

Multi-tabbed document workspace with hierarchical outline tree sidebar, fast in-page search (Ctrl+F), and Mica/Fluent visual styling.

🎨

GitHub Primer Themes

True GitHub Light and GitHub Dark theme tokens with high-contrast syntax highlighting powered by an offline C# engine.

Smart Repository Navigation

No more broken links when browsing local repository documentation.

Link Target Classification Behavior
#configuration IntraDocumentAnchor Instant smooth scrolling to element with deterministic heading ID.
./guides/install.md RelativeMarkdownFile Resolves relative to current document folder; opens in tab.
../api/auth.md#oauth CrossDocumentAnchor Opens target document and scrolls directly to heading anchor.
/docs/architecture.md RepositoryRootFile Discovers .git marker and resolves from repo root.
https://github.com/... ExternalWeb Safely dispatches URL to the default Windows browser.
../../../../Windows/System32 Unsupported (Sandbox) Traversal outside repository boundary blocked; diagnostic alerted.

Decoupled 10-Layer Architecture

Clean domain separation with pure .NET 10 core libraries and zero UI leakage.

Marknexia.Core

Immutable models, interfaces, and GitHub heading slug generation.

Marknexia.Files

Path canonicalizer, BOM/UTF encoding detection, repo root finder.

Marknexia.Navigation

Classification, sandboxing, and history stack manager.

Marknexia.Markdown

Markdig adapter with alerts, tables, and Mermaid block extraction.

Marknexia.Syntax

Offline ColorCode pure C# syntax highlighting.

Marknexia.Diagrams

Mermaid containers, copy source, and error boundaries.

Marknexia.Security

Ganss.Xss sanitizer and protocol allowlisting.

Marknexia.Rendering

HTML5 template engine, embedded CSS tokens, WebView2 bridge.

Marknexia.Infrastructure

SHA-256 LRU memory caches and JSON settings persistence.

Marknexia.App

WinUI 3 desktop shell, TabView, sidebars, search, and MSIX.
